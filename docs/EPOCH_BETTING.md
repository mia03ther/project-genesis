# Epochs & betting — game-loop core

Play money first: the default mode needs zero setup. Bets are in play
credits, labelled **演示积分 · 不是真钱** everywhere they appear
(`PLAY_MONEY_NOTE` in Python, `PLAY_MONEY_LABEL` in JS). There is no
wallet, no key, no network call in the betting path.

## Epoch

One epoch = 4 parallel mini-worlds ("civilizations": Aurora, Boreas,
Cinder, Dune), 5 residents each, 60 days by default (30–90 allowed).
Civilization `i` runs with seed `epoch_seed * 1000 + i` through the real
simulation engine. Each civilization gets an integer survival score:

```
score = alive * 1,000,000 + wealth_cents + total_health * 100
```

Population dominates in practice: one extra survivor outweighs any wealth
gap below 1,000,000 cents (golden epochs sit near 145,000). Highest score
wins; a tie is broken by the smallest
`SHA-256("genesis:epoch-winner:<epoch_digest>:<civ_id>")` — a pure function
of the digest, so anyone can recompute the winner. The epoch digest is the
SHA-256 of canonical JSON over the parameters plus each civilization's id,
name, seed, world digest and score inputs (integers and strings only, no
floats). `epoch_id` is `epoch:<seed>:<days>:<civs>:<residents>:<tax_bps>:<max_orders>`.

## Betting & settlement

A bet is `(player, civ, amount, epoch_id)`, amount in integer cents.
Settlement is parimutuel with **house fee 0**: winners split the whole
pool in proportion to stake (`stake * pool // winner_pool`, floor
division); the leftover cents (fewer than the number of winning bets) go
one cent each to the earliest winning bets in placement order, so payouts
always sum to exactly the pool. Edge cases: zero bets →
`outcome: "no_bets"`; nobody bet on the winner → **full refund of every
stake**, `outcome: "refunded_no_winner_bets"`, nothing rolls over.

## API (for the frontend builder)

Python — `genesis/epoch.py`, `genesis/betting.py`:

- `run_epoch(seed=42, days=60, num_civs=4, residents_per_civ=5, tax_rate_bps=0, max_orders_per_day=10) -> dict`
- `derive_winner(scores: list[tuple[int, int]], epoch_digest: str) -> int`
- `survival_score(alive, wealth_cents, total_health) -> int`
- `place_bet(bets, *, player, civ, amount, epoch_id, valid_civs) -> list[Bet]`
- `settle_epoch(epoch, bets) -> dict` (payouts in bet-placement order)
- CLI: `python main.py epoch --seed 42 --days 60 --bet alice:0:1000 --bet bob:1:2500`
  prints `{epoch, bets, settlement}` as JSON.

JavaScript — `frontend/engine.js` (also on `globalThis.GenesisEngine`):

- `runEpoch({seed, days, civs, residentsPerCiv, taxBps, maxOrders})`
- `deriveWinner(scores /* [{civ, score}] */, epochDigestHex)`
- `survivalScore(alive, wealthCents, totalHealth)`
- `placeBet(bets, {player, civ, amount, epochId, validCivs})` → new array
- `settleEpoch(epoch, bets)` → same settlement shape as Python
- `PLAY_MONEY_LABEL` — put this next to every bet amount in the UI.
- `civSeed(epochSeed, civIndex)`, `epochIdFor(...)`, `epochDigest(payload)`

Cross-checks: `node frontend/verify_epochs.mjs` (3/3 golden epochs,
winner + payouts bit-for-bit) and `node frontend/verify_engine.mjs`
(10/10 golden worlds). Golden data: `tests/golden_epochs.json`,
generated by `frontend/golden_epochs.py`. Tests: `tests/test_betting.py`.

## Real testnet (separate, clearly labelled path)

Shared facts live in `frontend/chain.json` — the single source of truth
both builders read (Python reads it via `genesis/chain.py`; the frontend
builder should read it instead of copying values into `app.js`). It holds
only already-verified facts: Monad Testnet chain 10143,
`https://testnet-rpc.monad.xyz`, `https://testnet.monadexplorer.com`,
GenesisLedger `0x0D903C5f9ae82e52aA69D39068EF80B85fAFaBA1`, the first live
transfer tx `0x4b66b46f…eae11` (1.5 MON, block 78228932) and the anchor tx
`0xd035cdda…fc433f` (seed-42 100-day digest). CLI:
`python main.py epoch --real-testnet` prints the facts plus the exact
`cast` / `monad verify` / `monad anchor` commands — and states explicitly
that no real bet has been placed and no real payout has happened.
